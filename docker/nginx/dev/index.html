backd dev stack

Released images over your own config. Saving a file in CONFIG_DIR reloads it.

Your backd

  • /readyz the API; try /v1/{realm}/…
  • /_ui/ the admin web interface (an administrator of a realm signs in)
  • /example/ the JavaScript client's example apps (run CONFIG_DIR=./examples/config make dev for their realms)

Observe

  • Grafana backd's dashboards; “Processes” shows the API and the worker apart
  • Prometheus targets backd, worker, executor and egress
  • MinIO console backd-dev / dev-p4ssw0rd!
