backd examples

Apps built with @backd/client on this server. Each realm's configuration is in examples/config.

Blog

Sign up, write posts, publish them, filter by author or category. Realm blog.

Expenses without functions

Share expenses in a group and see who owes whom. Its access rules are as strict as rules allow, and it still has known holes that only a server-side function can close. Realm expenses.

Expenses with functions

The same app, same layout, with those holes closed by five functions instead of client-trusted copies. Compare it with the version above. Realm expenses-with-functions.

Workshop tour

A guided walk through the server-side functions of the workshop realm, with an inspector that shows every call: request, answer, the function's log and a curl command. Realm workshop.

Mailbox

The emails the workshop realm would send, captured instead of delivered, with working links. Local development only.
